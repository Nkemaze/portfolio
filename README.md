## About this portfolio

This site is built with React and Vite. It includes an interactive project journal, an interactive technology section, responsive navigation, and light mode by default. The visual transitions respect reduced-motion preferences. No backend or environment variables are required.

## Run locally

Requires Node.js 22.12 or later and npm.

```sh
npm ci
npm run dev
```

Vite prints the local development URL in the terminal.

## Tests and production build

```sh
npm test
npm run build
npm run preview
```

The production site is generated in `dist/` and can be deployed to Vercel with `npm run build` as the build command and `dist` as the output directory.
